# Zaheen's Cake — zhcakes.com

Static website (HTML + CSS + JS, no build step) for GitHub Pages.
Works on phone, tablet and desktop. Orders go by Call / WhatsApp / Messenger — no backend needed.

```
index.html              the page
css/style.css           all styling (colours are at the top in :root)
js/main.js              menu, gallery filter, lightbox (swipe on phones)
js/gallery-data.js      list of gallery photos — generated by the script below
images/gallery/         watermarked photos + thumbnails (generated)
images/logo.svg         logo / favicon
images/og-cover.jpg     preview image when the link is shared on Facebook/WhatsApp (generated)
tools/watermark.py      watermark + gallery builder
photos/<category>/      YOUR ORIGINAL photos (ignored by git, never uploaded)
CNAME                   custom domain for GitHub Pages
```

## 1. Add your cake photos

1. Save the photos you want from the Facebook page (open photo → ⋯ → Download).
2. Put them in the right folder: `photos/birthday`, `photos/custom` or `photos/event`
   (for cupcakes, create `photos/cupcakes` and add a Cupcakes chip back in `index.html`).
3. Name files by what they are — the name becomes the caption:
   - `red-velvet-heart-cake.jpg` → "Red velvet heart cake"
   - add `[hero]` to show it in the big arched photo at the top: `unicorn-cake [hero].jpg` (2–4 is ideal)
   - add `[about]` for the round photo in the About section
4. Run:

```bash
pip install pillow
python tools/watermark.py
```

This resizes, fixes rotation, removes camera/GPS metadata, stamps the watermark, makes thumbnails, rebuilds
`js/gallery-data.js`, and removes gallery images whose original you deleted from `photos/`.

The default watermark (`--style cake`) puts a large angled "ZAHEEN'S CAKE / 01670-236621" across the
middle of the photo (over the cake), a faint repeating pattern over the whole picture, and a signature
in the corner, so the photo can't be cropped clean and reposted.

Watermark options:

```bash
python tools/watermark.py --opacity 0.75      # stronger watermark
python tools/watermark.py --style both --opacity 0.7
python tools/watermark.py --sub "zhcakes.com"  # change the small second line
```

Want your own font on the watermark? Drop a `.ttf` in `tools/fonts/`.

## 2. Preview

Open `index.html` in a browser, or run `python -m http.server` and open http://localhost:8000.

## 3. Publish on GitHub Pages

```bash
git add -A
git commit -m "New website"
git push
```

Repo → **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main` / root.
With the `CNAME` file the site serves at **zhcakes.com** (keep your current DNS records; tick *Enforce HTTPS*).
Not using the custom domain? Delete `CNAME`.
